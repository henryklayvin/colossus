# Colossus

Projeto em desenvolvimento com Java e Spring Boot.
Objetivos e funcionalidades estão em definição.

## Tecnologias da base

- Java 21
- Spring Boot 4.1.1
- Maven

## Executar localmente no Windows

Com o JDK 21 instalado, execute na pasta do projeto:

    .\mvnw.cmd spring-boot:run

A aplicação utiliza a porta 8080.

A configuração automática do banco e o Flyway estão temporariamente
desativados para permitir a execução inicial sem banco de dados.
